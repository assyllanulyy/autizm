# Сөздер әлеміне саяхат

3–4 сынып оқушыларына қазақ тіліндегі сөздер мен сөйлемдерді жаттықтыруға арналған шағын веб-ойын. Тыныш, тұрақты көрініс әдепкіде қосулы. Қалаған кезде жоғарғы бөліктегі **Түсті безендіру** батырмасымен түсті көріністі қосуға болады. Жоба HTML, CSS және JavaScript-пен жасалған; сервер, тіркелгі немесе ақылы құрал қажет емес.

## Іске қосу

1. Осы буманы жүктеп алыңыз.
2. `index.html` файлын Chrome, Edge, Firefox немесе Safari браузерінде ашыңыз.
3. Басты беттен деңгейді таңдап ойнаңыз. Интернетсіз де жұмыс істейді; қаріп жүктелмесе, жүйелік қаріп қолданылады.

## Ойындағы мазмұн

- 1-деңгей: суретке қарап заттың атауын табу.
- 2-деңгей: сөзге сай «кім? / не? / кімдер? / нелер?» сұрағын таңдау.
- 3-деңгей: жекеше және көпше сөздерді ажырату.
- 4-деңгей: сөздерді реттеп, қысқа сөйлем құрастыру.

Әр деңгейде 8, барлығы 32 тапсырма бар. Қате жауап жұлдызды азайтпайды, таймер жоқ. Тапсырма бетінің орналасуы тұрақты. Сөйлем құрастырудағы сөздер әр жолы бірдей ретпен шығады. Тапсырмалар мен жұлдыздар осы құрылғыдағы браузерде сақталады (`localStorage`). «Ойын барысын жаңарту» батырмасы сақталған нәтижені өшіреді. Көрініс таңдауы да осы құрылғыда сақталады.

## GitHub Pages-ке жариялау

1. GitHub-та жаңа репозиторий ашыңыз.
2. `index.html`, `styles.css`, `app.js` және `README.md` файлдарын репозиторийдің негізгі бумасына жүктеңіз.
3. Репозиторийдегі **Settings → Pages** бөліміне өтіңіз.
4. **Build and deployment** бөлімінде **Deploy from a branch** таңдаңыз. Branch ретінде `main`, folder ретінде `/(root)` таңдап, **Save** батырмасын басыңыз.
5. Pages бөлімі көрсеткен сайт сілтемесін ашыңыз. Жариялануы бірнеше минут алуы мүмкін.

## Қолжетімділік

Үлкен түрту аймақтары, тура әрі қысқа нұсқаулар, пернетақтамен басқарылатын батырмалар, фокус белгісі, экран оқырманына арналған кері байланыс, таймерсіз ойын және қателікті жазаламайтын хабарламалар бар. Қозғалыс пен сәндік элементтер әдепкіде азайтылған; көрнекі тапсырма белгілері сақталған. Телефонға және компьютерге бейімделеді. Балалардың жарыққа, түске, суретке және тапсырма қарқынына қалауы әртүрлі болуы мүмкін, сондықтан ойынды нақты баланың қажеттілігіне қарай реттеңіз.
